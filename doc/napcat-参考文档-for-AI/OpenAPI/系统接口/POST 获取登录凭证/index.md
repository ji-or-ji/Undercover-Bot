## POST 获取登录凭证

POST /get_credentials

获取登录凭证

> Body 请求参数

```json
{
  "domain": "qun.qq.com"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 否 |none|
|» domain|body|string| 是 |需要获取 cookies 的域名|
