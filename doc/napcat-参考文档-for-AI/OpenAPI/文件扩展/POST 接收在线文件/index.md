## POST 接收在线文件

POST /receive_online_file

> Body 请求参数

```json
{
  "user_id": "123456789",
  "msg_id": "123",
  "save_path": "C:\\save"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 否 |none|
|» user_id|body|string| 是 |用户 QQ|
|» msg_id|body|string| 是 |消息 ID|
|» element_id|body|string| 是 |元素 ID|
