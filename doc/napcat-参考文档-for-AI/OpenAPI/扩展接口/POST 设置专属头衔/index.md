## POST 设置专属头衔

POST /set_group_special_title

设置群聊中指定成员的专属头衔

> Body 请求参数

```json
{
  "group_id": "123456",
  "user_id": "123456789",
  "special_title": "头衔"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 否 |none|
|» group_id|body|string| 是 |群号|
|» user_id|body|string| 是 |QQ号|
|» special_title|body|string| 是 |专属头衔|
