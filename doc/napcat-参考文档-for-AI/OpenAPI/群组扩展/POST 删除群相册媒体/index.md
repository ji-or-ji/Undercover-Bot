## POST 删除群相册媒体

POST /del_group_album_media

> Body 请求参数

```json
{
  "group_id": "123456",
  "album_id": "album_id_1",
  "lloc": "media_id_1"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 否 |none|
|» group_id|body|string| 是 |群号|
|» album_id|body|string| 是 |相册ID|
|» lloc|body|string| 是 |媒体ID (lloc)|
